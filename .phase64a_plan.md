## 1. BubbleWidget API spec (new file `ui/bubble_widget.py`)

### Constructor
```python
BubbleWidget(message: str = "", character: str = "orange_cat",
             font_size: int = 16, padding: int = 14,
             max_width: int = 280, min_width: int = 120,
             tail_side: str = "bottom",   # "bottom" | "top" | "none"
             tail_offset_ratio: float = 0.5,  # 0.0=left, 1.0=right
             show_shadow: bool = True,
             parent: QWidget | None = None)
```

### Public properties / methods
- `set_message(text: str) -> None` — store text, recompute sizeHint, `updateGeometry()` + `update()`. Empty string allowed (renders placeholder "..." in TEXT_DIM if `_show_placeholder=True`).
- `set_character(character_id: str) -> None` — `_accent = QColor(_CHARACTER_ACCENT.get(character_id, _DEFAULT_ACCENT))`, `update()`.
- `set_typewriter_index(idx: int) -> None` — partial reveal. `idx == -1` = show all.
- `current_displayed_text() -> str` — helper for tests.
- `sizeHint() -> QSize` / `minimumSizeHint() -> QSize`.

### Module-level constants
- `OUTER_BORDER_W = 2` (dark outer)
- `MID_BORDER_W = 3` (character accent)
- `INNER_BORDER_W = 1` (cream highlight)
- `SHADOW_OFFSET = 4`
- `SHADOW_COLOR = QColor("#2A1A00")`
- `TAIL_WIDTH = 16`, `TAIL_HEIGHT = 10`
- `CORNER_BITE = 2`

### paintEvent z-order (no antialias, all axis-aligned drawRect)
1. Drop shadow (if enabled): `fillRect(SHADOW_OFFSET, SHADOW_OFFSET, body_w, body_h)` in SHADOW_COLOR.
2. Outer dark frame: `fillRect(0, 0, body_w, body_h, TEXT)`.
3. Accent mid frame: `fillRect(2, 2, body_w-4, body_h-4, _accent)`.
4. Cream fill: `fillRect(5, 5, body_w-10, body_h-10, BG_MID)`.
5. Corner bite: 4 small SHADOW_COLOR 2×2 squares at body corners (8-bit chamfer).
6. Inner top/left 1px BG_LIGHT highlight (bevel).
7. Tail (if not "none"): layered triangle (dark outline → accent → cream), 1px insets.
8. Text: `pixel_font(font_size)`, pen `TEXT`, `drawText(text_rect, AlignCenter | TextWordWrap, displayed_text)`.

### sizeHint
- Probe `QFontMetrics.boundingRect` with `inner_w_cap = max_width - 2*padding - 2*frame`.
- Pixel-snap body to even multiples.
- Add SHADOW_OFFSET and TAIL_HEIGHT to total size.

### Behavior
- `setSizePolicy(Preferred, Preferred)`.
- Long text > 8 lines → truncate with `…`.
- Embed-friendly: WA_TranslucentBackground handled by parent (NotificationWindow only).

```python
def _on_pet_item_changed(self, item):
    if self._populating:
        return
    if item.column() == 0:
        char_id = item.data(_CHAR_ID_ROLE) or "orange_cat"
        if char_id in CHARACTER_OPTIONS:
            if self._preview: self._preview.set_character(char_id)
            self._bubble_preview.set_character(char_id)
        return
    if item.column() != 2:  # 訊息 column
        return
    rows = self.pet_table.selectionModel().selectedRows()
    if not rows or rows[0].row() != item.row():
        return
    self._bubble_preview.set_message(item.text().strip())
```

## 5. Risks / edge cases

| Risk | Mitigation |
|---|---|
| Empty message | placeholder "..." in TEXT_DIM, frame visible at min size |
| Long text (>200 chars) | wrap to max_width, cap 8 lines, append `…` |
| Unknown character_id | `.get(character, _DEFAULT_ACCENT)` returns tan `#C8A96E` |
| itemChanged firing on init | `_populating` flag |
| `_on_pet_item_changed` non-displayed row | check selected_row == item.row() |
| CharacterDelegate writes 2 fields → 2 fires | idempotent, both re-read `_CHAR_ID_ROLE`, no-op visually |
| DPI scaling | integer pixel arithmetic + `NoAntialias` + even-multiple snap |
| Shadow clip in settings | `show_shadow=False` in preview |
| Tail tip mismatch | `(int(body_w*ratio), body_h+TAIL_HEIGHT-1)` |
| Translucent bg + child paint | Qt: children respect parent's WA_TranslucentBackground |
| Font metrics before fonts loaded | `apply_theme` runs at startup; BubbleWidget recomputes on `set_message` |
| Circular import | Move `_CHARACTER_ACCENT` + `_DEFAULT_ACCENT` to `bubble_widget.py`; `notification_window.py` re-imports for back-compat. One-way: `notification_window → bubble_widget`. |
